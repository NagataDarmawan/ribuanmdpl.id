## About

RibuanMDPL.id is a website concept for an open trip and private trip mountaineering service.

The project is designed to provide visitors with information about mountain destinations, trip packages, departure schedules, facilities, and registration procedures through a modern and user-friendly interface.

The website focuses on creating a convenient browsing experience for people interested in mountain adventures.

## Features

- **Mountain Destinations** — Explore various mountain destinations and their elevation information.
- **Trip Packages** — Browse open trip and private trip package information.
- **Departure Schedules** — Display upcoming hiking schedules and available slots.
- **Trip Details** — Present trip duration, pricing, and package information.
- **Photo Gallery** — Showcase mountain landscapes and hiking experiences.
- **Testimonials** — Display sample customer reviews.
- **FAQ Section** — Provide answers to frequently asked questions.
- **WhatsApp Integration** — Provide a contact shortcut for trip inquiries.
- **Responsive Design** — Optimized for desktop and mobile devices.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

Clone this repository to your local machine.

```bash
git clone https://github.com/NagataDarmawan/ribuanmdpl.id.git
```

### 2. Navigate to the Project

Move into the project directory.

```bash
cd ribuanmdpl.id
```

### 3. Install Dependencies

Install all required dependencies.

```bash
npm install
```

### 4. Run Development Server

Start the local development server.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
